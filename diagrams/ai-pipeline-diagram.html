Detection Types

  • Access: Unusual hours, frequency spikes, tailgating
  • Energy: Abnormal consumption patterns
  • Occupancy: Unexpected crowd density
  • Device: Sensor drift, offline patterns

Implementation

  • Library: PyOD (Isolation Forest, LOF, KNN)
  • Training: Per-tenant, scheduled nightly
  • Inference: Every 5 min batch or streaming
  • Feedback: Admin confirms/dismisses → model retrain
