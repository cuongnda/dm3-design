✅ Tracking Setup Checklist

  • GTM container snippet added to all pages
  • Microsoft Clarity snippet added
  • Cookie consent banner (GDPR)
  • Custom event tracking (analytics.js)
  • dataLayer initialized on all pages
  • Replace GTM-XXXXXXX with real GTM container ID
  • Replace CLARITY_PROJECT_ID with real Clarity project ID
  • Create GA4 property and link to GTM
  • Set up GA4 conversion goals (demo request, contact form)
  • Create Looker Studio dashboard and embed above
  • Set up GTM triggers for custom events
  • Configure Clarity heatmaps for key pages

🔧 How to Connect Real Data

  1. Create a Google Tag Manager container → replace GTM-XXXXXXX in js/cookie-consent.js and all HTML files
  2. Create a GA4 property → add GA4 tag in GTM
  3. Create a Microsoft Clarity project → replace CLARITY_PROJECT_ID in js/cookie-consent.js
  4. In GTM, create triggers for custom events: cta_click, form_submit, scroll_depth, language_switch
  5. Create a Looker Studio report → embed iframe in the Traffic Overview section above
