## 4. Page briefs

## 4.1 Platform overview

- **URL:** `/platform/`
- **Audience:** buyers evaluating the overall platform, technical evaluators, decision-makers comparing modular platform vs point tools
- **Primary keyword:** building operations and security platform
- **Core promise:** one shared foundation for identity, devices, events, audit, integrations, and deployment across all modules
- **Main CTA:** Book a demo
- **Supporting CTA:** Explore modules
- **Must cover:**
  - shared identity, auth, RBAC
  - realtime events and live status
  - audit trail and operational history
  - integration-ready architecture
  - cloud / on-premise / hybrid deployment
  - why modular expansion is easier on one platform
- **Allowed proof:** one backend, shared data/event foundation, multi-tenant design, shared console, APIs/event flows
- **Assets needed:** platform diagram, shared-foundation visual, product screenshots
- **Open questions:** none if based on current docs

## 4.2 Access Control

- **Primary keyword:** access control system
- **Core promise:** manage doors, gates, lifts, and critical access points from one realtime system
- **Main CTA:** Book a demo

- **Must cover:**

  - live status and event visibility
  - permissions and policy management
  - auditability and response

## 5. Writing rules for every page

- Lead with a recognizable buyer problem, not internal architecture language
- Explain the module or solution first, then connect it back to the shared platform
- Use concrete operational language: doors, visitors, vehicles, events, operators, audit, response
- Keep AI secondary unless the page is the intelligence page
- Do not invent vertical-specific brand stories; keep one Duall Master product identity
- Do not over-claim integrations, partner programs, compliance, or roadmap items

## 7. Definition of done for a page brief

A page is ready for design/dev when it has:
- [ ] approved headline and subhead
- [ ] section-by-section copy draft
- [ ] approved CTA
- [ ] allowed proof points only
- [ ] internal link targets
- [ ] metadata draft
- [ ] asset request list
- [ ] unresolved claims removed or marked

If those are missing, the page is still strategy, not production.
